UK Housing Market Analysis

Project Overview

This project explores trends in the UK housing market using official government property transaction data. The analysis focuses on housing price trends, regional comparisons, property types, and market patterns using Python-based data analysis techniques.

The project demonstrates data cleaning, exploratory data analysis, visualization, and analytical storytelling skills commonly used in data analyst roles.

⸻

Dataset

Source:
UK Land Registry Price Paid Data

The dataset contains residential property transactions across the UK, including:

* property prices
* transaction dates
* property types
* locations
* county information

⸻

Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab
* GitHub

⸻

Key Analysis Performed

1. Regional Housing Price Analysis

* Identified the most expensive counties in the UK
* Compared London housing prices against the rest of the UK

2. Time-Series Analysis

* Analyzed housing market trends over time
* Visualized average property price growth

3. Property Type Analysis

* Compared detached, semi-detached, terraced, and flat prices
* Evaluated differences in average market values

4. Data Cleaning

* Removed missing values
* Checked duplicate records
* Filtered unrealistic price values

5. Correlation Analysis

* Created a heatmap to analyze relationships between variables

⸻

Key Insights

* London properties remain significantly more expensive than the rest of the UK
* Detached homes had the highest average prices across the dataset
* UK housing prices showed strong long-term upward growth trends
* Property market trends accelerated after 2020
